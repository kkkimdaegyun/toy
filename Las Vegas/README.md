# 🎲 카지노 나이트 - 사내 멀티플레이 보드게임

사내 LAN에서 동료들과 즐기는 실시간 멀티플레이 카지노 주사위 배치 보드게임입니다.

> ⚠️ 이 게임은 **가상의 보드게임 상금**만 사용합니다.  
> 실제 금전 거래, 결제, 입출금 기능은 없습니다.

---

## 📋 프로젝트 소개

- **장르**: 카지노 주사위 배치 전략 보드게임
- **인원**: 2~4명
- **모드**: 주사위 모드 / 카드 모드
- **언어**: 한국어 UI
- **통신**: 실시간 WebSocket (Flask-SocketIO)

---

## 🛠 설치 방법

### 요구 사항
- Python 3.10 이상
- Windows (서버 호스트)
- Chrome 또는 Edge (모든 플레이어)

### 설치

```bash
py -m pip install -r requirements.txt
```

---

## 🚀 실행 방법

```bash
py app.py
```

서버가 시작되면 다음과 같이 표시됩니다:

```
==================================================
   카지노 나이트 - 사내 멀티플레이
==================================================

내 PC:
  http://127.0.0.1:1336

사내 접속 주소:
  http://192.168.0.32:1336

게임 서버가 실행되었습니다.
==================================================
```

---

## 🌐 사내망 접속 방법

1. 서버를 실행한 PC와 **같은 LAN(Wi-Fi 또는 유선)**에 연결되어 있어야 합니다.
2. 서버 시작 시 표시되는 **사내 접속 주소**를 브라우저에 입력합니다.
3. 예시: `http://192.168.0.32:1336`

### 1336 포트 설명
- 이 게임은 **포트 1336**을 사용합니다.
- 다른 프로그램이 이 포트를 사용 중이면 서버가 시작되지 않을 수 있습니다.

---

## 🔥 Windows Defender 방화벽

동료들이 접속할 수 없는 경우:

1. **Windows Defender 방화벽** → **앱 허용**
2. Python을 **프라이빗 네트워크**에서 허용
3. 또는 다음 명령어를 관리자 권한으로 실행:

```powershell
netsh advfirewall firewall add rule name="Casino Night" dir=in action=allow protocol=TCP localport=1336
```

### 접속이 안 될 때 확인사항
- ✅ 같은 LAN에 연결되어 있나요?
- ✅ 올바른 IPv4 주소를 사용하고 있나요?
- ✅ 포트 1336이 방화벽에서 허용되어 있나요?
- ✅ Python이 프라이빗 네트워크에서 허용되어 있나요?
- ⚠️ 일부 회사 네트워크는 클라이언트 간 직접 통신(Client Isolation)을 차단합니다.

---

## 🎮 게임 방법

### 방 만들기
1. 닉네임을 입력합니다.
2. 주사위 색상을 선택합니다 (빨강/주황/노랑/초록).
3. **방 만들기** 버튼을 클릭합니다.
4. 생성된 방 코드 또는 초대 링크를 동료에게 공유합니다.

### 색상 선택
- 4가지 색상: 🔴 빨강, 🟠 주황, 🟡 노랑, 🟢 초록
- 이미 선택된 색상은 **사용 중**으로 표시됩니다.
- 한 방에서 같은 색상은 한 명만 사용할 수 있습니다.

### 게임 시작
1. 2~4명이 참가하면
2. 방장이 **게임 시작** 버튼을 누릅니다.

---

## 🎯 선 정하기

- 게임 시작 시 모든 플레이어가 주사위 1개를 굴립니다.
- **가장 낮은 숫자**를 굴린 사람이 **선(첫 번째 플레이어)**이 됩니다.
- 가장 낮은 숫자가 동률이면, 동률인 플레이어들만 다시 굴립니다.

---

## 🎲 주사위 모드

1. 각 플레이어는 **8개의 주사위**를 가지고 시작합니다.
2. 자기 차례가 되면 **남은 주사위를 모두 굴립니다**.
3. 나온 숫자 중 **하나를 선택**합니다.
4. 해당 숫자가 나온 주사위를 **모두** 같은 번호의 카지노에 배치합니다.
5. 시계 방향으로 다음 플레이어에게 차례가 넘어갑니다.

### 예시
주사위 결과: 1, 1, 3, 3, 3, 5
- **3**을 선택하면 → 카지노 3에 주사위 **3개** 배치
- 남은 주사위: 3개 (1, 1, 5)

---

## 🃏 카드 모드 (커스텀 규칙)

주사위 대신 **숫자 카드**를 뽑습니다.
- 남은 토큰 수만큼 카드를 뽑습니다.
- 나온 숫자 중 하나를 선택해 같은 숫자의 토큰을 모두 배치합니다.
- 카지노 정산 방식은 주사위 모드와 **동일**합니다.

---

## 💰 카지노 배당금

- 6개의 카지노가 있습니다 (카지노 1~6).
- 게임 시작 시 54장의 지폐를 섞어 각 카지노에 배분합니다.
- 각 카지노는 총 배당금이 **$100,000 이상**이 될 때까지 지폐를 받습니다.

---

## ⚡ 동률 무효 규칙 (가장 중요!)

**같은 카지노에서 같은 개수의 주사위를 가진 플레이어들은 모두 무효가 됩니다!**

### 예시 1
| 플레이어 | 주사위 수 | 결과 |
|---------|----------|------|
| 🔴 빨강 | 4개 | ❌ 무효 |
| 🟠 주황 | 4개 | ❌ 무효 |
| 🟡 노랑 | 1개 | ✅ 1등 |
| 🟢 초록 | 0개 | - |

빨강과 주황이 동률(4개)이라 **둘 다 무효**!  
노랑이 1개만으로 **최고 상금**을 가져갑니다.

### 예시 2
| 플레이어 | 주사위 수 | 결과 |
|---------|----------|------|
| 🔴 빨강 | 4개 | ❌ 무효 |
| 🟠 주황 | 4개 | ❌ 무효 |
| 🟡 노랑 | 2개 | ❌ 무효 |
| 🟢 초록 | 2개 | ❌ 무효 |

두 개의 동률 그룹이 있으면 **전원 무효**! 아무도 상금을 받지 못합니다.

## 🏆 승리 조건

- 모든 카지노가 정산되면 각 플레이어의 **총 획득 상금**을 비교합니다.
- 가장 많은 상금을 획득한 플레이어가 **우승**합니다.
- 동일한 최고 금액이 있으면 **공동 우승**입니다.

## 🔄 재접속

- 브라우저를 새로고침해도 게임에 다시 참가할 수 있습니다.
- 재접속 토큰이 브라우저에 저장됩니다.
- 닉네임, 색상, 좌석, 게임 상태가 모두 복원됩니다.

---

## ❓ 문제 해결

| 문제 | 해결 방법 |
|------|----------|
| 서버가 시작되지 않음 | `py -m pip install -r requirements.txt` 재실행 |
| 포트 사용 중 오류 | 다른 프로그램이 1336 포트를 사용하고 있지 않은지 확인 |
| 동료가 접속 불가 | 방화벽 설정 확인, 같은 LAN 확인 |
| LAN IP 확인 | `ipconfig` 명령어에서 IPv4 주소 확인 |
| 게임이 멈춤 | 연결 끊긴 플레이어의 재접속을 기다리는 중일 수 있음 |
| 화면이 깨짐 | Chrome 또는 Edge 최신 버전 사용 권장 |
