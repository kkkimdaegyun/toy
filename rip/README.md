# 🪦 퇴사자 사이버 묘지 (Resign In Peace)

먼저 더 좋은 곳으로 떠난 동료들을 묘비로 기리는 슬프고도 웃긴 토이 프로젝트.

- **Backend**: FastAPI (Python)
- **Frontend**: 단일 `index.html` (CSS/JS 내장, 프레임워크 없음)
- **DB**: SQLite — 등록한 묘비는 **파일로 영구 저장** (기록용)
- **공유**: 같은 네트워크(LAN)의 동료도 접속 가능 (HTTPS 없음, 순수 HTTP)

---

## 🚀 실행하기 (Windows · Docker 없이)

### 방법 1) 더블클릭 (가장 쉬움)
파일 탐색기에서 **`run.bat` 더블클릭**.
- 처음 한 번은 의존성(fastapi, uvicorn)을 자동 설치합니다.
- 잠시 후 브라우저가 `http://localhost:8000` 으로 **자동으로 열립니다.**

### 방법 2) 명령어로
PowerShell 또는 명령 프롬프트에서 이 폴더로 이동한 뒤:
```powershell
py app.py
```
실행하면 콘솔에 주소와 **기록 파일 위치**가 표시되고, 브라우저가 자동으로 열립니다.

> 💡 `python` 이 *"인식되지 않습니다"* 라고 나오면 **`py`** 를 쓰세요.
> `py` 런처(`C:\Windows\py.exe`)는 항상 PATH 에 있어 가장 확실합니다.
> (참고: 이미 열려 있던 터미널은 PATH 변경이 반영되지 않으니, 새 터미널을 열면 `python` 도 동작합니다.)
> 의존성 오류가 나면 한 번만: `py -m pip install -r requirements.txt`

> 브라우저 자동 열기를 끄고 싶으면 `set OPEN_BROWSER=0` 후 실행하세요.
> 포트를 바꾸려면 `set PORT=9000` 처럼 지정하면 됩니다.

## 🌐 같은 네트워크(LAN)에서 동료와 공유하기

기본적으로 `0.0.0.0` 으로 떠서, **같은 와이파이/사내망의 동료들도 접속**할 수 있습니다.

1. `python app.py`(또는 `run.bat`) 실행 시 콘솔에 공유 주소가 표시됩니다:
   ```
   이 컴퓨터에서      :  http://localhost:8000
   같은 네트워크 동료 :  http://192.168.0.42:8000   ← 이 주소를 동료에게 공유
   ```
2. 동료는 같은 네트워크에서 브라우저로 `http://<당신의 IP>:8000` 에 접속하면 됩니다.
3. **Windows 방화벽** 허용 창이 뜨면 **'액세스 허용'**(특히 '개인 네트워크')을 누르세요.
   안 뜨거나 접속이 안 되면 방화벽에서 Python 의 사설 네트워크 인바운드를 허용하면 됩니다.

## 💾 기록은 어떻게 저장되나요? (중요)

- 등록한 **모든 묘비는 `data\graveyard.db` (SQLite 파일)** 에 저장됩니다.
- **서버를 껐다 켜도(`python app.py` 다시 실행) 이전 기록이 그대로 남습니다.**
- 누가 퇴사할 때마다 화면의 **＋ 버튼**으로 추가하면, 떠난 사람들의 명단이 차곡차곡 쌓입니다.
- **백업**: `data\graveyard.db` 파일을 복사해 두면 됩니다.
- **완전히 새로 시작**: `data\graveyard.db` 파일을 삭제하면 빈 묘지로 초기화됩니다.

> 참고: 묘비를 잔디밭 위 **어디에 두었는지(드래그 위치)** 는 브라우저(localStorage)에 저장됩니다.
> 이름·직무·퇴사일·태그·묘비명 같은 **기록 내용 자체는 DB 파일**에 안전하게 남습니다.
> (다른 PC/브라우저에서 열면 내용은 그대로지만 묘비 배치는 처음엔 기본값으로 흩뿌려집니다.)

## ✍️ made by (기여자 크레딧)

묘지(잔디밭) **아래쪽**에 묘비를 **기록하거나 수정한 사람들(기록한 사람=수정자)** 의 이름이
`made by ...` 한 줄로 표시됩니다.
- 새로운 사람이 묘비를 추가/수정할 때마다 그 사람의 이름이 **목록에 누적**되어 점점 길어집니다.
- 예: `made by 균, 영서`

## 🛑 종료하는 법

콘솔 창에서 **`Ctrl + C`** 를 누르면 서버가 종료됩니다. **기록은 그대로 유지**되며, 다음에 다시 켜면 이전 묘지가 복원됩니다.

## 기능 / API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET    | `/`               | 묘지 메인 페이지 |
| GET    | `/api/graves`     | 퇴사자 목록 조회 |
| POST   | `/api/graves`     | 퇴사자 등록 (＋ 버튼) |
| DELETE | `/api/graves/{id}`| 퇴사자 삭제 (－ 파묘 모드) |
| GET    | `/api/credits`    | 기록/수정한 사람 목록(누적) |

## (선택) Docker 로 실행

로컬 `python app.py` 가 기본이지만, 원하면 컨테이너로도 띄울 수 있습니다:
```bash
docker compose up --build      # → http://localhost:8000
```
이 경우 기록은 `graveyard-data` 볼륨에 저장됩니다.

> ⚠️ 로컬(127.0.0.1) 전용 토이 프로젝트이며, 외부에 노출하지 마세요.
