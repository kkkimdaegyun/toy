# 과일 땡!

같은 회사 네트워크에서 동료 2~4명이 브라우저로 즐기는 실시간 과일 반응 카드 게임입니다. 각 플레이어가 공개한 **가장 위 카드만** 보고, 같은 과일이 **정확히 5개**가 되는 순간 `SPACE`로 종을 칩니다.

상용 게임의 로고나 카드 그림을 사용하지 않았습니다. 과일 카드, 캐릭터, 종, 화면 구성은 HTML/CSS로 직접 만든 독자적인 디자인입니다.

## 설치

서버로 사용할 Windows PC에서 PowerShell 또는 명령 프롬프트를 열고 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
py -m pip install -r requirements.txt
```

동료 PC에는 별도 프로그램을 설치할 필요가 없습니다. Chrome 또는 Edge만 있으면 됩니다.

## 실행

```powershell
py app.py
```

기본 포트는 `1337`이며, 한 개의 Python 서버가 웹 화면과 실시간 통신을 모두 제공합니다. 실행하면 다음 주소가 표시됩니다.

- 내 PC: `http://127.0.0.1:1337`
- 사내 접속 주소: `http://내-PC의-IPv4:1337`

서버는 `0.0.0.0:1337`에서 실행되므로 같은 사내망의 동료는 화면에 표시된 사내 접속 주소로 들어오면 됩니다. 인터넷 연결이나 외부 CDN은 필요하지 않습니다.

## 방 만들기와 참가

1. 닉네임과 캐릭터를 고릅니다.
2. 한 명이 **방 만들기**를 누릅니다.
3. 대기실의 **초대 링크 복사**로 동료에게 주소를 보냅니다.
4. 함께할 동료들이 링크를 열고 방에 참가합니다.
5. 방장이 아닌 플레이어들이 **준비**를 누릅니다.
6. 2명 이상이 연결되고 참가한 모두가 준비되면 방장이 **게임 시작**을 누릅니다.

닉네임은 공백을 제외하고 1~12자여야 하며 같은 방에서 중복 사용할 수 없습니다. 게임은 최소 2명부터 시작할 수 있고 방 정원은 최대 4명입니다.

## 게임 방법

- 총 56장의 카드를 서버가 안전하게 섞어 모든 플레이어에게 차례대로 나눕니다. 2명은 28장씩, 3명은 19·19·18장, 4명은 14장씩 받습니다. 3명 게임의 한 장 차이는 무작위로 정한 카드 배분자와 첫 차례에 따라 매 게임 달라집니다.
- 차례인 플레이어는 자신의 숨은 카드 더미, **카드 뒤집기**, 또는 `ENTER`를 눌러 한 장을 공개합니다.
- 카드 값은 서버가 공개하는 순간 네 화면에 함께 전송됩니다. 어떤 브라우저도 다음 카드의 종류나 순서를 미리 받지 않습니다.
- 각 플레이어의 공개 카드 중 **가장 위에 보이는 카드 한 장만** 셉니다. 새 카드에 덮인 이전 카드는 계산에서 빠집니다.
- 보이는 딸기·바나나·라임·자두 중 하나라도 합계가 **정확히 5개**이면 누구나 `SPACE`로 종을 칠 수 있습니다.
- 정확히 5개가 되면 **다음 카드 공개는 종 판정이 끝날 때까지 잠깁니다.** 카드 뒤집기 버튼·카드 더미·`ENTER` 모두 차단되고, 먼저 도착한 카드 공개 요청도 서버가 거절해 현재 공개 카드를 유지합니다. 정답 종으로 카드를 가져간 뒤 승자가 다음 카드를 공개합니다.
- 5개는 정답이지만 6개, 7개 등은 오답입니다. 두 종류가 동시에 각각 5개여도 정답입니다.
- 카드가 덮이면서 이전 과일이 빠져 합계가 5가 되는 순간도 종을 칠 수 있습니다.

마우스를 사용하는 경우 게임판 중앙의 큰 종을 눌러도 됩니다. 스페이스바를 길게 눌러도 한 번만 처리되며, 승자는 브라우저 시간이 아니라 **서버에 먼저 도착한 순서**로 결정됩니다.

게임은 효과음 없이 무음으로 동작합니다. 종 입력과 판정은 화면 애니메이션과 문구로 확인할 수 있습니다.

## 정답과 오답

### 정답

가장 먼저 올바르게 종을 친 플레이어가 테이블의 모든 공개 카드 더미를 가져갑니다. 가져간 카드는 자신의 숨은 카드 더미 맨 아래로 들어가며, 그 플레이어가 다음 카드를 공개합니다.

### 오답 페널티

정확히 5개가 아닌데 종을 치면 오답 플레이어의 숨은 카드에서 다른 활동 중인 플레이어에게 1장씩 줍니다. 카드 값은 누구에게도 공개되지 않으며 공개 카드들은 그대로 남습니다.

오답 플레이어의 카드가 부족하면 다음 좌석부터 시계 방향으로 한 장씩 주고, 모두에게 주었거나 카드가 0장이 되면 멈춥니다. 카드를 새로 만들지 않습니다. 거의 동시에 여러 명이 오답 종을 눌러도 첫 입력 한 건만 처리하고, 뒤따른 입력은 페널티 없이 무시합니다.

## 카드가 없어졌을 때와 승리 조건

숨은 카드가 0장이 된 플레이어는 관전 상태가 됩니다.

- 이후 카드 공개 차례에서 제외됩니다.
- 종을 칠 수 없습니다.
- 빠른 반응은 계속 보낼 수 있습니다.
- 마지막으로 공개한 카드와 그 아래 공개 더미는 누군가 정답으로 가져갈 때까지 테이블에 남아 계산에 포함됩니다.

숨은 카드가 남은 플레이어가 한 명뿐이면 즉시 게임이 끝나고 그 플레이어가 승리합니다. 공개 카드 수는 생존 판정에 포함하지 않습니다. 방장은 같은 플레이어 구성으로 새 덱을 만들어 다시 하거나 대기실로 돌아갈 수 있습니다.

## 재접속

브라우저는 방과 플레이어를 복구하기 위한 안전한 재접속 토큰을 로컬에 저장합니다. 새로고침하거나 잠시 연결이 끊겨도 같은 닉네임, 캐릭터, 좌석, 카드 수, 차례로 돌아옵니다.

게임 중 한 명의 연결이 끊기면 카드 공개와 종 입력을 잠시 멈춥니다. 해당 플레이어가 돌아오면 자동으로 이어집니다. 방장이 새로고침해도 방장 권한은 유지됩니다.

## Windows Defender Firewall

동료가 접속하지 못한다면 다음을 확인합니다.

1. 모두 같은 회사 LAN 또는 같은 Wi-Fi에 연결되어 있는지 확인합니다.
2. 서버 창에 표시된 IPv4 주소와 `1337` 포트를 사용했는지 확인합니다.
3. Windows 보안 → **방화벽 및 네트워크 보호** → **방화벽을 통해 앱 허용**에서 Python을 찾습니다.
4. Python의 **개인 네트워크** 접근을 허용합니다.
5. 처음 실행할 때 Windows 방화벽 창이 나타나면 개인 네트워크를 선택해 허용합니다.

회사 네트워크가 기기 간 통신을 차단하는 클라이언트 격리 정책을 사용하면 같은 Wi-Fi여도 접속할 수 없습니다. 이 경우 사내 네트워크 담당자에게 PC 간 `TCP 1337` 통신이 가능한지 문의하세요.

## 문제 해결

### 사내 접속 주소가 표시되지 않음

명령 프롬프트에서 `ipconfig`를 실행하고 사용 중인 어댑터의 **IPv4 주소**를 확인합니다. `http://IPv4주소:1337` 형식으로 접속합니다.

### 포트가 이미 사용 중임

다른 프로그램이 `1337` 포트를 사용 중인지 확인하고 종료한 뒤 `py app.py`를 다시 실행합니다.

### 화면은 열리지만 연결 끊김으로 표시됨

브라우저를 새로고침하고 서버 창이 계속 실행 중인지 확인합니다. 회사 보안 프로그램이 WebSocket 연결을 막는지도 확인하세요.

### 방에 다시 들어갈 수 없음

기존 플레이어 자리는 새로고침 재접속을 위해 유지됩니다. 처음 참가했던 동일한 브라우저 프로필로 다시 열어주세요.

## 자동 테스트

```powershell
py -m unittest discover -s tests -v
```

테스트에는 정확한 56장 구성, 2·3·4명 인원별 카드 배분, 보이는 카드 계산, 덮인 카드, 정확히 5개, 정답 수집, 오답 이동, 부족한 페널티 카드, 탈락, 승리, 숨은 카드 비노출, 동시 종 입력, 카드 공개와 종 입력의 경합, 스페이스 중복 방지, 실시간 클라이언트 동기화, 새로고침 재접속이 포함됩니다.

```text

templates/index.html      모든 한국어 화면

tests/                    규칙·동시성·실시간 통합 테스트
requirements.txt          Python 의존성
```
